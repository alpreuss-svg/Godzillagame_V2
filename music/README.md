# Eigene Musik (bleibt lokal)

Lege hier deine eigenen, legal erworbenen Soundtrack-Dateien ab (.mp3/.ogg).
Der Ordner wird nicht auf GitHub hochgeladen. Fehlt eine Datei, spielt das Spiel ein selbst komponiertes Ersatzstück.

Die genauen Dateinamen pro Level werden mit dem Musiksystem festgelegt (noch nicht gebaut).
